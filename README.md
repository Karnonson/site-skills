# Household tools

Small tools for the house.

## Shopping list

- `python3 shopping.py add <item>`: add an item (at most 50, no item twice, whatever its capital letters)
- `python3 shopping.py list`: show the list
- `python3 shopping.py remove <item>`: remove an item

The list is kept in `shopping.txt` in the folder the command is run from; set `SHOPPING_FILE` to use another file.
