# Changelog

## [0.2.0] - 2026-11-25

### Added

- Add an item to the shopping list, so it is not forgotten at the shop: `python3 shopping.py add <item>`. An item already in the list, whatever its capital letters, is refused, and so is any addition beyond 50 items.
- See the list, to know what to buy: `python3 shopping.py list`.
- Remove an item once bought, so the list stays right: `python3 shopping.py remove <item>`.
